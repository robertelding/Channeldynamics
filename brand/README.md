# Brand

## Eldingo! (new brand, October 2026)
- Wordmark: **Helvetica Neue Bold**, tracking −3.5%, converted to outlines in the SVGs so no font is needed to display it.
  On the website use Inter or Hanken Grotesk for headings (free Helvetica Neue look-alikes) unless a Helvetica Neue web licence is bought.
- Colours: Brand red **#E4130E**, Spark yellow **#FFC83D**, Ink **#14181D**, Mist #F4F5F7, Line #E3E6EA. White space first; never dark-mode pages.
- Files:
  - `eldingo-wordmark.svg` (red, static) · `-animated.svg` (bulb flickers on, spokes burst) · `-ink.svg` · `-quiet.svg` (no spokes)
  - `eldingo-mark.svg` (the exclamation "spark" on its own) · `-animated.svg` · `-quiet.svg`
  - `eldingo-favicon.svg` / `-dark.svg` and PNGs at 16, 32, 180, 512
  - `eldingo-logo-system.html` — the sheet showing everything in use; `eldingo-logo-concepts.html`, `eldingo-font-options*.html` — the exploration
- The animation: bulb grey → flicker → spark; eight spokes burst out and settle. Use once on page load and on hover; never loop.
